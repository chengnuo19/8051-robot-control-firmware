# 8051 Robot Control Firmware

一个面向 8051 双轮小车的模块化 C 固件示例，涵盖循迹、避障、串口停车命令和基础外设控制。

## 功能模块

- 四路红外循迹与 PID 差速控制
- HC-SR04 测距与近距离制动
- OpenMV UART 指令接收；`0x02` 命令触发定点停车
- 双路电机、双舵机、软件 I²C OLED 和定时器模块
- 电机、舵机、循迹、测距和 UART 测试模式

## 硬件与构建

代码使用 8051 `reg52.h` 和 `sbit` 语法，面向 Keil C51 或兼容工具链。仓库未包含 IDE 工程文件或具体开发板生成配置；请在工具链中创建目标工程并加入这些 `.c` 文件。

引脚分配、循迹电平和晶振频率在 `config.h` 中配置。默认设置为 11.0592 MHz 晶振和 9600 baud。修改接线或传感器输出极性后，应同步调整该文件。

硬件上车验证尚未随此源码提供；在接入电机前先使用对应测试模式核对引脚和传感器读数。
